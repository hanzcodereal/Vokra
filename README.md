## Build APK Release manual

Jalankan dari direktori project:

```bash
flutter pub get
flutter build apk --release
```

APK hasil build berada di:

`build/app/outputs/flutter-apk/app-release.apk`

Untuk distribusi publik, konfigurasi signing release Android perlu diisi dengan keystore milik penerbit sebelum APK dipublikasikan.
